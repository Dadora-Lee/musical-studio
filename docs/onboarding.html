필수 도구

도구최소 버전설치 방법 (Windows)
Node.js20+winget install OpenJS.NodeJS

2. 리포지토리 클론 AUTO

WSL2 ext4에 클론 (반드시 /home 아래)

Windows 측 /mnt/c/는 HMR이 10배 느림. 반드시 ~/projects/ 사용.

cd ~/projects
git clone https://github.com/Dadora-Lee/musical-studio.git
cd musical-studio

SSH 키 등록되어 있다면 SSH URL도 가능:

git clone git@github.com:Dadora-Lee/musical-studio.git

3. 환경변수 설정 USER

두 가지 파일 — 차이 명확히

파일용도커밋?
.env.exampleplaceholder 템플릿YES
.env.local실제 시크릿 값 (Next.js 자동 로드)NO (.gitignore)
.env/secrets.env마스터 시크릿 보관 (선택)NO (.gitignore)

다음 명령으로 시작:

cp .env.example .env.local
# 그 후 .env.local 을 메모장이나 nano로 열어 값 채우기

채워야 할 값들

  • GitHub Fine-grained PAT (Contents/Administration/PR write)
  • Supabase: URL, anon key, service_role key, JWT secret, DB password
  • Google OAuth: Client ID, Client Secret, redirect URIs 설정
  • HOST_LAN_IP (PowerShell ipconfig로 확인)
  • DDNS_HOSTNAME (외부 접근 시)

각 값의 출처는 .env.example 주석 참조.

4. 의존성 설치 AUTO

pnpm install

최초 1회는 5-10분. 이후 캐시.

5. Supabase 로컬 스택 선택

클라우드 Supabase에 바로 붙어도 되지만, 마이그레이션/seed 실험은 로컬에서. Docker Desktop 실행 중이어야 함.

pnpm supabase:start          # Docker 컨테이너 5개 띄움 (1-2분)
# Studio: http://localhost:54323
# API:    http://localhost:54321
# DB:     postgresql://postgres:postgres@localhost:54322/postgres

6. 개발 서버 실행 AUTO

pnpm dev                     # → http://localhost:3000

Next.js Fast Refresh 작동. 코드 저장 즉시 반영.

7. 외부 접속 (LAN/WAN) 선택

같은 LAN (사무실/집 같은 WiFi)

pnpm dev -- --hostname 0.0.0.0          # 또는 next.config.ts 설정
# 파트너 접속: http://<본인 PC LAN IP>:3000

다른 LAN (인터넷 너머)

준비물: 공유기 포트포워딩 + DDNS

  1. 공유기 admin → 포트포워딩: 외부 3000 → 내부 <PC LAN IP>:3000
  2. DDNS 등록: freedynamicdns.net 또는 noip/duckdns
  3. 접속: http://musicalstudio.freedynamicdns.net:3000
보안: Next.js middleware로 dev 환경 토큰 인증 적용. 토큰은 .env.local의 DEV_ACCESS_TOKEN 참조.

8. 테스트 실행 AUTO

pnpm test                 # Vitest (단위 + 통합)
pnpm test:watch           # watch mode
pnpm test:e2e             # Playwright (headless)
pnpm test:e2e:ui          # Playwright UI mode

자세한 전략: docs/testing.md.

9. 문제 해결

pnpm install 실패

Node 버전 확인: node --version ≥ 20. 미달이면 nvm install 20 또는 winget으로 업그레이드.

Supabase start 실패

Docker Desktop 실행 중인지. WSL Integration ON인지 확인.

dev server port 충돌

lsof -i :3000                 # 사용 중인 프로세스 확인
kill -9 <PID>
# 또는 다른 포트: pnpm dev -- --port 3001

Google OAuth callback 실패

  1. Google Cloud Console → Credentials → Redirect URIs 확인
  2. Supabase → Authentication → URL Configuration 확인
  3. 브라우저 쿠키/localStorage 비우고 재시도
