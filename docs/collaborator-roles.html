항목 Owner (Dadora-Lee) Collaborator (파트너)
GitHub 계정 ✅ 본인 + repo 소유 필수 (본인 계정)

본인 Gmail (앱 로그인) ✅ Test users 등록됨 본인 Gmail (Owner가 Test users로 추가)

Vercel 현재 보류
WSL2 + Docker ✅ 본인 PC 설치 시나리오에 따라 (아래 참조)
DDNS 가입 ✅ Owner (dev server hosting) 불필요
공유기 포트포워딩 ✅ Owner 불필요
핵심 원칙: 개발 인프라(DB/Auth/DDNS)는 Owner 단독 관리. Collaborator는 본인 GitHub 계정만 필수.

시나리오 A — Collaborator가 본인 PC에서 개발

Collaborator 자기 PC에 설치

  • Node 20+
  • pnpm
  • git
  • gh CLI
  • WSL2 + Docker (Windows 시)

Owner 측 작업

  • GitHub collaborator 초대
  • Google Test users 추가
  • .env.local 값 안전 채널로 전달
  • (선택) Supabase 멤버 초대

Collaborator 셋업 명령

git clone https://github.com/Dadora-Lee/musical-studio.git
cd musical-studio
cp .env.example .env.local        # 값 채우기 (Owner가 전달)
pnpm install
pnpm dev                          # → http://localhost:3000

자세한 단계: onboarding.html

시나리오 B — Collaborator가 SSH로 Owner PC 접속

Collaborator 자기 PC에 설치

  • SSH 클라이언트 (Windows OpenSSH, macOS/Linux 기본)
  • GitHub SSH 키 (github.com/<you>.keys 에 등록되어 있어야 함)
  • (선택) VSCode Remote SSH extension

Owner 측 작업

  • WSL2 안에서 bash scripts/sudo-bootstrap.sh 실행 (1회)
  • 공유기에 포트 2222 포트포워딩 추가
  • Windows Firewall 2222 inbound 허용
  • Owner WSL에서 ssh-import-id gh:<partner>

Collaborator 접속 명령

# LAN 안 (같은 WiFi)
ssh -p 2222 soswolf@192.168.31.101

# 인터넷 (다른 LAN)
ssh -p 2222 soswolf@musicalstudio.freedynamicdns.net

# 접속 후 작업
cd ~/projects/musical-studio
git pull
pnpm dev

자세한 SSH 워크플로: ssh-guide.html

신규 파트너 합류 시 Owner 1회 명령

# Owner WSL 안에서
PARTNER=<partner-github-username>

# 1) GitHub collaborator
gh api --method PUT /repos/Dadora-Lee/musical-studio/collaborators/$PARTNER -f permission=push

# 2) SSH key 자동 등록
ssh-import-id "gh:$PARTNER"

# 3) Google Test users는 Web에서 직접:
#    console.cloud.google.com → Audience → Test users → ADD USERS

# 4) .env.local 값을 안전 채널(Bitwarden/1Password)로 공유
echo "✅ $PARTNER 합류 완료"

FAQ

Q. 공동 개발자도 Supabase 가입해야 하나요?

아니요. Owner가 만든 프로젝트의 anon key만 받아서 사용하면 됩니다.

Q. Google Cloud Console에 추가되어야 하나요?

불필요. 본인 Gmail이 Test users에 등록되어 있으면 OAuth 로그인 가능.

Q. 공동 개발자가 본인 PC에서 dev server를 띄울 수 있나요?

가능합니다. .env.local 셋업 후 pnpm dev. Owner의 Supabase 프로젝트에 붙어 동작.

Q. 공동 개발자가 자기만의 dev 환경을 만들려면?

자기 Supabase 프로젝트 + Google OAuth Client를 별도 발급하면 가능. 단, DB가 분리되어 협업 데이터 공유 불가. MVP 단계엔 비추.
