MusicXML 마디 간격 결정 기록

Git 공유용 문서입니다. Musical Studio prototype의 악보 spacing 정책을 비교한 뒤 B형으로 진행하기로 결정했습니다.

Demo index

결정

B. 균등 연습형으로 진행합니다. 한 줄을 4개 마디 칸으로 나누고, 각 마디 폭을 최대한 균등하게 맞추는 방향입니다.

선택 이유

  • 배우가 MR/AR를 들으며 현재 위치를 빠르게 찾기 쉽습니다.
  • “몇 마디부터 다시” 같은 연습 지시와 잘 맞습니다.
  • 녹음 피드백을 특정 마디/구간에 연결하기 좋습니다.
  • 추후 MR timeline, Recording timeline, Score cursor를 같은 시간축으로 연결하기 쉽습니다.

수용하는 단점

  • 가사가 긴 마디는 실제 악보형보다 답답하게 보일 수 있습니다.
  • 출판 악보 느낌보다는 연습 도구 느낌이 강해집니다.
  • 음표 밀도가 높은 구간은 OSMD가 완전 균등 폭을 보장하지 못할 수 있습니다.

비교 결과 요약

A. 실제 악보형 가독성은 좋지만, 마디 폭이 자연스럽게 달라져 피드백 위치 지정과 timeline 매칭이 B보다 덜 직관적입니다.
B. 균등 연습형 선택됨. 마디 위치를 찾기 쉽고 연습/녹음/피드백 prototype 목적에 가장 잘 맞습니다.
C. 원본 보존형 원본 악보와 가깝지만, 페이지당 마디 수와 줄 배치가 불규칙해 앱 연습 UX 기준과 충돌할 수 있습니다.

실제 구현 지침

  1. 기본 목표는 4 measures per system입니다.
  2. A4 한 페이지에는 가능한 한 12~16 measures가 들어오도록 유지합니다.
  3. MusicXML 원본의 임의 줄바꿈/페이지 나눔은 prototype 연습 레이아웃에서는 제거하거나 무시합니다.
  4. OSMD가 완전 균등 폭을 지원하지 않는 경우, 가능한 범위에서 균등에 가깝게 조정하고 편차를 Playwright로 측정합니다.
  5. 검증 기준은 “마디 위치 찾기 쉬움”, “페이지 안에서 잘리지 않음”, “타이틀 유지”, “MR seek 영향 없음”입니다.
