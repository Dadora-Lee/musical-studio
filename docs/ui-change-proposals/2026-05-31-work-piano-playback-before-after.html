변경 목적

영향 범위

유지 좌측 Number 목록, 상단 NickName 선택, 중앙 A4 MusicXML 영역, 하단 Transport/Recording, 우측 제출/Feedback 위치
변경 악보재생 source label과 동작을 피아노 연주로 전환한다. transport 버튼과 slider는 MR/AR와 같은 의미로 작동한다.
추가 MusicXML playback event parser, Tone.js piano player wrapper, ScoreViewer raw XML callback, measure 기반 cursor/page sync
삭제 소리 없는 interval 기반 cursor-only playback 의미는 제거한다. 단 cursor/page sync 기능은 피아노 연주 위치 추적으로 재사용한다.
보류 고품질 피아노 sample pack, part selector, repeat/grace/dynamic/pedal 완전 지원, Recording과 피아노 연주 동시 녹음 정책

승인 기준

  • /work의 큰 레이아웃은 바꾸지 않는다.
  • 사용자에게 보이는 source 이름은 악보재생에서 피아노 연주로 바뀐다.
  • 자동 검증은 playback state와 scheduling 중심으로 하고, 실제 소리는 브라우저에서 수동 청음으로 확인한다.
  • 새 dependency, DB schema, Supabase migration, 실제 MusicXML/MR/AR 파일 추가는 하지 않는다.

되돌릴 기준

  • MR/AR 재생 또는 Recording 흐름이 깨지면 피아노 연주 통합을 되돌린다.
  • MusicXML 없는 Number에서 transport가 오동작하면 unavailable 상태로 되돌린다.
  • 큰 악보에서 browser freeze가 발생하면 event 수 guard를 낮추고 part selector를 별도 제안한다.
