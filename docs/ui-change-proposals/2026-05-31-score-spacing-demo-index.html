MusicXML 마디 간격 Demo 선택

실제 앱 적용 전에 3가지 악보 spacing 정책을 HTML demo로 비교합니다. 원하는 방향을 선택해주면 그 기준으로 변경 전/후 제안서를 만들고 구현 단계로 넘어가겠습니다.

추천

A. 실제 악보형

4마디/줄, 12~16마디/페이지를 유지하되 마디 폭은 가사와 음표 밀도에 맞춰 자연스럽게 둡니다.

  • 가독성 좋음
  • 실제 악보 느낌 유지
  • 마디 폭은 완전 동일하지 않음
Demo A 보기
연습 위치 우선

B. 균등 연습형 - 선택됨

한 줄을 4개 칸으로 나누어 마디 폭을 최대한 동일하게 맞춥니다.

  • 마디 위치 찾기 쉬움
  • 피드백 기준 지정에 유리
  • 가사 긴 마디는 압축될 수 있음
Demo B 보기 결정 기록 보기
원본 우선

C. 원본 보존형

MusicXML 원본의 줄바꿈과 페이지 나눔을 최대한 존중합니다.

  • 원본 악보와 가장 가까움
  • 페이지당 마디 수가 들쑥날쑥할 수 있음
  • 앱 연습 UX와 맞추기 어려울 수 있음
Demo C 보기
선택 기준: Musical Studio의 1차 목표가 “배우가 MR/AR를 들으며 악보를 보고 녹음하고, 특정 위치에 피드백을 받는 것”이므로 B. 균등 연습형으로 진행하기로 결정했습니다. 이 결정은 피드백 위치 지정, 마디 단위 반복 연습, MR timeline과 악보 위치 매칭을 우선합니다.
