수정한 리뷰 항목

리뷰 항목처리 결과검증 증거
REC-WEBM 무음 저장 webm recording blob을 silent WAV로 성공 처리하던 fallback을 제거하고, decode-first WAV 변환으로 변경했다. 변환 실패 시 local take를 만들지 않고 사용자 error를 표시한다. PracticeStudio.test.tsx에 non-silent WAV PCM 검증 추가
REC-UNMOUNT race unmount 중 active MediaRecorder의 handler를 끊고 stop한 뒤 stream track을 정리한다. 뒤늦은 finalize/save를 차단한다. PracticeStudio.test.tsx에 unmount 중 recorder cleanup 검증 추가
MXML backup/forward timing MusicXML measure child node를 문서순으로 순회하고, backup/forward로 playback cursor를 조정한다. measure duration은 cursor end max 기준으로 계산한다. playback-events.test.ts에 multi-voice/forward 회귀 테스트 추가
Tie continuation duplicate tie type="stop" continuation note는 새 event로 재타격하지 않고 cursor만 전진한다. sustain duration 병합은 후속 범위로 남겼다. playback-events.test.ts에 tied continuation 테스트 추가

보류 / 승인 필요 항목

  • DB migration/RLS: schema/RLS 변경이므로 별도 ADR과 사용자 승인 후 진행한다.
