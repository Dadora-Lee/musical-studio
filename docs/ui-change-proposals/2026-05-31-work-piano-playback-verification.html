구현 요약

  • 악보재생 source를 피아노 연주 source로 전환했다.
  • MusicXML raw string을 ScoreViewer와 piano parser가 공유하도록 onMusicXmlLoaded callback을 추가했다.
  • MusicXML note/rest/chord/measure/tempo를 playback event map으로 변환하는 parser를 추가했다.
  • 기존 dependency인 Tone.js를 client-only dynamic import로 사용하는 piano player wrapper를 추가했다.
  • 피아노 연주의 play, pause, stop, 10초 이동, slider seek, measure 기반 cursor/page sync를 연결했다.
