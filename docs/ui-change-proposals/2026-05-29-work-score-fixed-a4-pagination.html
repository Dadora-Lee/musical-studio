악보 영역 A4 고정 + 페이지 넘김 변경 제안

현재 /work 화면의 좌측 Number 목록, HeaderLayout, 하단 MR/AR/악보재생 transport, 우측 제출/Feedback 영역은 유지하고, 중앙 MusicXML 악보 표시 방식만 변경한다.

변경 전 / 변경 후

변경 전: 전체 페이지 세로 나열

Number 목록 유지
MusicXML 악보 1 / 70
MR / AR / 악보재생 transport 유지
제출 / Feedback 유지
  • OSMD가 만든 페이지들이 모두 세로로 쌓여 스크롤이 매우 길어진다.
  • A4 종이 한 장의 높이가 중앙 영역보다 커서 악보가 과하게 크게 보인다.
  • 상단 페이지 버튼이 있어도 실제 화면에는 다음 페이지들이 계속 이어져 보인다.

변경 후: A4 한 페이지 고정 + 페이지 전환

Number 목록 유지
MusicXML 악보 1 / 70
MR / AR / 악보재생 transport 유지
제출 / Feedback 유지
  • 중앙 악보 영역은 남은 높이 안에서 A4 비율을 유지한다.
  • 한 번에 현재 페이지 하나만 보이고, 나머지 페이지는 잘라서 숨긴다.
  • 다음/이전 페이지 버튼으로 OSMD 페이지를 전환한다.

수정 대상

  • ScoreViewer: OSMD 페이지 중 현재 페이지 외에는 `display: none`으로 숨긴다.
  • ScoreViewer A4 frame: `height: 100%`, `aspect-ratio: 210 / 297`, `overflow: hidden` 기준으로 중앙 영역 안에 맞춘다.
  • PracticeStudioLayout: 중앙 MusicXML 영역의 높이를 하단 transport 위에서 고정하고, 내부 긴 스크롤을 제거한다.
  • ScorePager: 기존 이전/다음 페이지 버튼은 유지하며 실제 표시 페이지와 연결한다.

유지되는 요소

  • 좌측 Number 목록 위치와 역할은 유지한다.
  • 우측 제출 상태, 녹음 Take 목록, Feedback 표시 방식은 유지한다.
  • 하단 MR/AR/악보재생 transport와 Recording timeline 위치는 유지한다.
  • MusicXML 렌더링 방식은 OSMD를 계속 사용한다.
주의: 한 페이지에 들어가는 마디 수 자체는 MusicXML/OSMD engraving 설정의 영향을 받는다. 이번 변경은 먼저 “한 화면에 A4 한 장만 보이게 잘라내는 것”에 집중하고, 마디 밀도 조정은 다음 단계에서 별도 승인 후 진행하는 것이 안전하다.
추천 승인안: 변경 후 방식으로 진행한다. 즉, 중앙 악보는 A4 한 장 높이로 고정하고, 현재 페이지 외 페이지는 숨긴 뒤 이전/다음 버튼으로 넘기도록 구현한다.
