MR/AR 재생 안정화 1단계 제안

목표는 현재 구현된 HTMLAudio 기반을 유지하면서, MR/AR가 실제로 재생되는지 명확히 보이고 사용자가 현재 위치를 클릭하거나 드래그해서 이동할 수 있는 트랙 UX를 먼저 완성하는 것입니다.

1단계 구현 범위

우선 적용

MR/AR 재생 확인

  • MR/AR 선택 시 연결된 파일명, 준비 상태, 현재 시간/전체 시간을 명확히 표시합니다.
  • 재생/일시정지/정지/10초 이동은 현재 선택한 MR 또는 AR 오디오에만 적용합니다.
우선 적용

Interactive MR Track

  • 기존 passive bar를 접근 가능한 range slider 기반 seek bar로 바꿉니다.
  • played 구간, playhead, thumb 색상을 분리해서 현재 위치를 한눈에 보이게 합니다.
다음 단계

녹음 파형/동기화

  • Recording lane은 이번 단계에서 유지하되, 실제 waveform과 녹음 seek는 녹음 안정화 단계에서 진행합니다.
  • 장치 선택/모니터링은 기존 접힘 패널을 유지합니다.

검증 기준

  • MR 파일이 있는 넘버에서 MR 탭을 선택하고 재생하면 시간이 증가해야 합니다.
  • AR 파일이 있는 넘버에서 AR 탭을 선택하고 재생하면 같은 컨트롤로 재생되어야 합니다.
  • seek bar를 클릭/드래그하면 표시 시간이 바뀌고, 실제 오디오 위치도 이동해야 합니다.
  • MR/AR 파일이 없는 넘버에서는 재생/seek 컨트롤이 비활성화되어야 합니다.
  • 기존 좌측 넘버 목록, 중앙 악보 A4 영역, 우측 제출/피드백 패널 레이아웃은 변경하지 않습니다.

추천 진행: 이 제안대로 승인되면 테스트를 먼저 추가하고, `PracticeTransport` 내부의 MR/AR 오디오 상태와 `TimelineTrack`만 좁게 수정하겠습니다. 악보 재생, 녹음 저장, 피드백 목록 UI는 이번 단계에서 구조 변경하지 않습니다.
