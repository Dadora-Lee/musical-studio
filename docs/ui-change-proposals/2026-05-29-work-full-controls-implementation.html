구현 체크리스트

1. 악보 표시

  • A4 paper view 유지
  • 이전/다음 페이지가 실제 page display와 연결되는지 보강
  • 페이지 이동 시 OSMD 전체 reload 방지 유지

2. MR/AR 재생

  • MR/AR source 선택 유지
  • 재생/일시정지/정지/10초 전/10초 후 실제 오디오 연결
  • 진행 시간, 전체 시간, 진행바 실제 오디오 상태 동기화
  • 파일 미등록 시 버튼 비활성화와 이유 표시

3. 악보재생

  • OSMD cursor 기반 마디 이동 유지
  • 재생/일시정지/정지/이전/다음 위치 연결
  • cursor 위치가 보이는 영역으로 scroll 되도록 보강
  • Tone.js 실제 음 재생은 구현 가능성 검토 후 별도 표시

4. 녹음

  • MediaRecorder 지원 확인
  • 마이크 권한 요청 및 실패 상태 표시
  • 녹음 시작 시 MR과 동시에 진행 가능
  • Recording track이 MR track 아래에서 같이 진행
  • 정지 후 WAV Blob 생성 및 임시 Take 목록 추가

5. 장치/볼륨

  • navigator.mediaDevices.enumerateDevices()로 input/output 후보 표시
  • 브라우저 제한으로 output 선택이 불가능하면 상태 문구 표시
  • MR volume과 monitor/recording volume을 분리

6. 제출/Feedback

  • 기존 제출/Feedback 위치 유지
  • 새 Take 클릭/Feedback 보기 흐름 유지
  • 실제 Supabase 제출은 이번 단계에서 하지 않고 local prototype 상태로 유지
변경하지 않을 것
  • 좌측 Number 목록 위치 이동/삭제 없음
  • HeaderLayout 위치 변경 없음
  • 오른쪽 제출/Feedback 영역 위치 변경 없음
  • 새 DB schema 또는 Supabase remote 변경 없음
  • Soundslice 런타임 의존성 추가 없음
