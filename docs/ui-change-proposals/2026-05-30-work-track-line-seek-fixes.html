Track 선 기반 Seek 개선 제안

목표는 MR/AR Track을 더 단순하고 조작 가능한 오디오 편집기 스타일로 정리하는 것입니다. 동그라미 thumb는 제거하고, 진행 위치는 세로 선으로 표시하며, 선을 이동하면 해당 위치에서 바로 노래가 나오도록 안정화합니다.

이슈 리스트와 해결 루프

순서 이슈 원인 확인 해결 검증
1 동그라미 thumb가 시각적으로 거슬림 range input 기본 thumb가 보이고, 별도 현재 위치 선과 중복됩니다. CSS로 thumb 숨김 현재 위치는 세로 선만 남깁니다. 시각 확인 MR/AR Track에 동그라미가 없어야 합니다.
2 AR 진행 색상이 채워지지 않음 source 전환 후 progress와 label이 같은 track 컴포넌트에서 안정적으로 갱신되는지 확인합니다. MR/AR 공통 activeAudioProgress를 명시적으로 계산합니다. AR seek AR에서 이동 시 진행 색상과 선이 함께 이동해야 합니다.
3 선 이동 후 해당 위치에서 노래가 나와야 함 seek 시 audio.currentTime만 바뀌고 재생 상태 유지가 보장되는지 확인합니다. seek handler 강화 재생 중이면 이동 후 계속 재생, 정지 중이면 위치만 이동합니다. 재생 중 drag 이동 직후 표시 시간과 오디오 위치가 같아야 합니다.
4 실제 총 몇 분인지 표시 필요 metadata 로드 전 fallback duration과 실제 audio duration이 섞입니다. 표시 우선순위 정리 실제 metadata duration을 우선 표시하고, 로드 전만 DB durationLabel을 씁니다. metadata 로드 MR/AR 각각 실제 총 시간이 보입니다.

반복 방식

루프 수행 내용 중단 기준
Loop 1 위 4개 이슈를 테스트와 구현으로 해결합니다. unit + browser smoke에서 MR/AR seek, 색상, disabled 상태가 모두 확인됩니다.
Loop 2 남은 이슈를 다시 리스트업합니다. 새 리스트가 없거나, 다음 단계인 Recording 파형/동기화 범위로 넘어갈 때 멈춥니다.
Loop 3+ 새 이슈가 있으면 같은 방식으로 원인 확인 → 해결 → 검증을 반복합니다. 사용자 확인 또는 검증 통과 후 다음 milestone로 이동합니다.

승인 후 구현 범위는 PracticeTransport와 해당 테스트에 한정합니다. 좌측 Number 목록, 중앙 A4 악보 영역, 우측 제출/피드백 패널은 이동하거나 삭제하지 않습니다.
