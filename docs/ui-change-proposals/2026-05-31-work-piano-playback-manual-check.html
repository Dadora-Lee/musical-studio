변경 전/후 2026-05-31-work-piano-playback-before-after.html

1차 확인 순서

  1. /work에 접속한다.
  2. 좌측 Number 목록, 상단 NickName, 중앙 악보, 하단 Transport, 우측 제출/Feedback 영역 위치가 유지되는지 확인한다.
  3. 중앙 MusicXML 악보가 A4 영역 안에 표시되는지 확인한다.
  4. 하단 source 버튼이 MR, AR, 피아노 연주로 보이는지 확인한다.
  5. 피아노 연주를 선택한다.
  6. 슬라이더 라벨이 피아노 연주로 바뀌고 활성화되는지 확인한다.
  7. 재생 버튼을 눌러 피아노 계열 소리가 나는지 직접 청음한다.

조작 확인

  1. 재생을 눌렀을 때 현재 시간이 증가하는지 확인한다.
  2. 일시정지를 눌렀을 때 시간이 멈추는지 확인한다.
  3. 정지를 눌렀을 때 시간이 00:00으로 돌아가는지 확인한다.
  4. 10초 전, 10초 후 버튼이 피아노 연주 위치를 이동시키는지 확인한다.
  5. 슬라이더를 드래그했을 때 해당 위치로 이동하는지 확인한다.
  6. 피아노 연주 위치 이동에 따라 악보 cursor/page가 따라가는지 확인한다.

정상 기준

  • 피아노 연주 선택 시 앱이 멈추지 않는다.
  • 피아노 계열 reference 소리가 들린다.
  • 슬라이더와 시간 표시가 같은 위치를 가리킨다.
  • MR/AR source로 다시 바꿔도 기존 MR/AR 재생이 유지된다.
  • Recording 버튼과 Take/Feedback 영역이 기존 위치에 남아있다.

문제 기록 기준

  • 피아노 소리가 나지 않으면 브라우저, 볼륨, source, 선택한 Number를 기록한다.
  • 악보 cursor가 따라가지 않으면 어느 시점에서 멈췄는지 기록한다.
  • MR/AR 전환 후 소리가 겹치면 어떤 source에서 어떤 source로 바꿨는지 기록한다.
  • 브라우저 콘솔에 play() request was interrupted가 뜨면 재현 순서를 기록한다.
  • 악보가 로딩되지 않으면 선택한 Number와 화면의 오류 문구를 기록한다.

참고

현재 피아노 연주는 1차 prototype이다. MusicXML 전체 part를 간단히 병합해 Tone.js synth로 재생하므로, 실제 피아노 샘플 음색이나 정교한 repeat/dynamic/articulation 처리는 후속 단계에서 다룬다.
