원인과 수정

문제 오디오 API가 Range 요청에도 200 OK만 반환해서 브라우저가 MP3를 seek 가능한 파일로 인식하지 못했습니다.
수정 Accept-Ranges, Content-Range, 206 Partial Content 응답을 추가했습니다.
수정 파일 src/app/api/prototype-assets/[numberId]/[kind]/route.ts
현재 상태 seekableEnd: 400.43102로 브라우저가 전체 길이를 seek 가능 구간으로 인식합니다.

MR Track 상태 예시

Playwright 검증 시점 기준 진행률은 약 69.9247%입니다.

직접 확인 순서

  1. http://localhost:3000/work를 엽니다.
  2. 좌측 Number 목록에서 기본 선택된 곡 또는 원하는 곡을 선택합니다.
  3. 하단 Transport 영역에서 MR이 선택되어 있는지 확인합니다.
  4. MR Track 선을 원하는 위치로 드래그합니다.
  5. 우측 시간 표시가 이동한 위치로 바뀌고, 선/재생 위치가 같은 지점으로 이동하는지 확인합니다.
