요약

현재 피아노 연주는 MusicXML에서 추출한 이벤트를 Web Audio로 재생하면서 OSMD 커서를 이동시키는 방식이다. 이 때문에 악보가 자동으로 움직이고, 사용자는 연습 중 위치를 잃기 쉽다.

1차 목표는 악보 페이지를 고정하고 현재 마디 또는 음표만 색상으로 표시하는 것이다. 가사는 Zoom과 마디 수 조절로 읽기 쉽게 만들고, 볼륨은 스피커 아이콘 popover로 접으며, 재생 버튼은 Play/Pause 토글로 현재 상태를 보여준다.

진행 Workflow

1. 승인HTML 선택안 확인 후 방향 확정
2. 구현악보 고정, 하이라이트, 보기 설정, transport 개선
3. 검증Unit test와 Playwright로 실제 화면 확인
4. 복구문제 목록화 후 수정 루프 반복
5. 공유결과 HTML, 스크린샷, 커밋 준비

목표별 상세 계획

목표 수정 방향 검증 기준
악보 고정 피아노 재생 중 goToMeasure 기반 자동 이동을 중단하고, 현재 마디/음표 하이라이트 API를 추가한다. 재생 중 A4 영역이 움직이지 않고 하이라이트만 바뀐다.
가사 가독성 100%, 125%, 150% Zoom과 3/4마디 보기 설정을 제공한다. 설정 변경 후 악보가 잘리지 않고 title과 lyric이 유지된다.
볼륨 정리 항상 보이는 slider를 스피커 아이콘 popover로 접는다. waveform은 다음 단계 후보로 남긴다. popover open/close와 volume 값 반영이 동작한다.
재생 상태 Play/Pause를 하나의 primary toggle button으로 합치고 active 상태를 시각적으로 표시한다. MR/AR/Piano 모두 현재 상태가 버튼에 반영된다.

구현 순서

  1. 사용자가 선택안 HTML을 보고 A/B/C 방향을 승인한다.
  2. ScoreViewer에 현재 마디 하이라이트용 controller API를 설계한다.
  3. 피아노 재생의 measure change에서 자동 page reveal을 제거한다.
  4. 현재 마디 overlay 또는 SVG highlight를 구현한다.
  5. Zoom과 measures per line 설정을 추가하고 OSMD 재렌더링을 검증한다.
  6. 볼륨 slider를 popover로 이동한다.
  7. Play/Pause toggle과 active/disabled 상태를 정리한다.
  8. Unit test와 Playwright 검증을 갱신한다.
  9. 검증 결과 HTML과 스크린샷을 저장한다.

검증 계획

  • pnpm lint
  • pnpm typecheck
  • pnpm test
  • Playwright: /work 진입, MusicXML title, A4 fit, 피아노 재생, 악보 고정, 현재 마디 하이라이트 확인
  • Playwright: Zoom/마디 수 변경, volume popover, MR/AR/Piano play/pause toggle 확인
