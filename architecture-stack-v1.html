2. 핵심 흐름

1. Google 로그인

Supabase Auth Google Provider로 로그인하고 users.role로 권한을 결정합니다.

2. Drive 파일 등록

관리자가 Drive의 MusicXML/PDF/MR 파일을 연결하고 file id, mime type을 저장합니다.

3. Work 연습

부원은 본인 배역 넘버에서 악보를 넘기며 MR을 듣고 연습합니다.

4. WAV 녹음 저장

동기화 기준 원본은 WAV로 Supabase Storage에 저장합니다.

5. 숙제 제출/피드백

연습 녹음 중 하나를 제출하고, 연출가는 제출현황과 코멘트를 관리합니다.
